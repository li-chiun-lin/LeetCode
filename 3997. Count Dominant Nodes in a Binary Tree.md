# Medium

You are given the $root$ of a complete binary tree.

A node $x$ is called dominant if its value is equal to the maximum value among all nodes in the subtree rooted at $x$.

Return the number of dominant nodes in the tree.

```cpp
class Solution {
    int dfs(TreeNode* root, int& ans)
    {
        if (root == nullptr)
            return 0;

        int v = max(dfs(root->left, ans), dfs(root->right, ans));

        if (v <= root->val)
            ++ ans;

        return max(v, root->val);
    }

public:
    int countDominantNodes(TreeNode* root) {
        int ans = 0;

        dfs(root, ans);

        return ans;
    }
};
```
