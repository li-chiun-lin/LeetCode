# Easy

You are given an integer $n$.

The score of $n$ is defined as the sum of $d \times freq(d)$ over all distinct digits $d$, where $freq(d)$ denotes the number of times the digit $d$ appears in $n$.

Return an integer denoting the score of $n$.

```cpp
class Solution {
public:
    int digitFrequencyScore(int n) {
        int sum = 0;

        while (n)
        {
            int d = n % 10;
            n /= 10;

            sum += d;
        }

        return sum;
    }
};
```
