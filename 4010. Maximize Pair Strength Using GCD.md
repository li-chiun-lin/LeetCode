# Easy

You are given an integer array $nums$.

Choose exactly one pair of distinct indices $i$ and $j$. The strength of the pair is defined as $(nums[i] * nums[j]) / gcd(nums[i], nums[j])^2$.

Return the maximum strength over all possible pairs.

```cpp
class Solution {
public:
    long long maxPairStrength(vector<int>& nums) {
        long long ans = 0;
        int n = size(nums);

        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j)
            {
                long long a = (long long)nums[i] * nums[j];
                long long b = gcd(nums[i], nums[j]);
                b = b * b;
                ans = max(ans, a / b);
            }

        return ans;
    }
};
```
