# Medium

You are given three integers $l$, $r$, and $k$.

An integer $y$ is said to be a perfect kth power if there exists an integer $x$ such that $y = x^k$.

Return the number of integers $y$ in the range $[l, r]$ (inclusive) that are perfect $k$-th powers.

```cpp
class Solution {
private:
    // Helper function to find the number of x >= 0 such that x^k <= limit
    long long countPowersUpTo(long long limit, int k) {
        if (limit < 0) return 0;
        if (limit == 0) return 1; // Only 0^k = 0
        if (k == 1) return limit + 1; // Every number is a 1st power

        // Approximate the k-th root
        long long res = std::pow(limit, 1.0 / k);

        // Adjust for floating-point inaccuracies
        while (std::pow(res + 1, k) <= limit) {
            res++;
        }
        while (std::pow(res, k) > limit) {
            res--;
        }

        return res + 1; // +1 to include 0^k
    }

public:
    int countKthRoots(int l, int r, int k) {
        // Total powers up to r minus total powers up to l-1
        return countPowersUpTo(r, k) - countPowersUpTo(l - 1, k);
    }
};
```
